# Contributing to Soul Dashboard

Thanks for checking out the Soulverse! This is a 3D interactive dashboard built with React Three Fiber.

## Ways to Contribute

- **Report bugs** — open an issue with reproduction steps
- **Suggest features** — especially new visualization types or agent panels
- **Fix issues** — look for `good-first-issue` labels
- **Improve docs** — README, inline comments, SPEC.md

## Quick Start

```bash
git clone https://github.com/uncommonpope-png/soul-dashboard.git
cd soul-dashboard
npm install
npm run dev
```

## Pull Request Process

1. Fork the repo and create a branch from `master`
2. Run `npm run build` to verify nothing is broken
3. Keep PRs focused — one feature/fix per PR
4. Link to the related issue if applicable
